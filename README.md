**Commands**

```bash
>>>help
Available commands:
help - Show this help message
exit - Exit the console
clear(or cls) - Clear the console
osint - Start OSINT tools
scan - Start scanning tools
info - Show information about the tool
update - Update the tool to the latest version
export - Export the findings to a file
import - Import data from a file
chat - Start chat tools
dos - Mark user for shutdown or restart by HWID
ghwid - Get HWID of user by name and password
```
